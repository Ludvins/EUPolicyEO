Catalogue evidence review

Read each question, open the source records, and judge how much evidence each candidate provides. Candidate order is shuffled. Each question covers one catalogue.

  • 2 · Direct evidence. The source supports the requested measurement or research method and the stated scope.
  • 1 · Useful partial evidence. The source provides a relevant variable, transferable method or useful context with a clear gap.
  • 0 · Unrelated. The source offers no useful evidence for this question.

Leave a candidate unscored if you cannot verify it. Add a brief reason to each rating. Date or geographic coverage by itself does not establish that the record measures the requested variable.
